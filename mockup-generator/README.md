# Мокап-генератор

Сторінка `index.html` ставить фото товарів (навантажувачів) на фон і масово перейменовує файли. Відкривається у браузері, сервер не потрібен.

- **1 фото:** обрати фон, обрати фото, підправити розмір, позицію й тінь, зберегти з потрібною назвою.
- **Масова зміна:** завантажити свої файли. Фото на білому фоні автоматично вирізаються (за краями або через AI в браузері) і ставляться на фон, решта копіюється з новою назвою. На виході ZIP і `мапінг.xlsx`.

Ця версія **без даних HELI**. Внутрішня збірка з відповідністю «код ↔ модель» робиться локально і в репозиторій не потрапляє:

```
node build-mockup-tool.js <report.json>              # внутрішня, НЕ публікувати
node build-mockup-tool.js --public [bg.jpg] [out]    # ця сторінка
```
